Einführung

In diesem Beispiel werden praktische Anwendungsfälle in R gezeigt, wie das Nextreme-Package, welches die Inhalte des Arbeitsblattes DWA-A 531 umsetzt, verwendet werden kann. Beispielhaft werden die 5-Minuten-Niederschlagssummen der Wetterstation Görlitz verwendet, die frei über das Climate Data Center (CDC) des Deutschen Wetterdienstes (DWD) verfügbar sind.

Ein Überblick über die Ziele und einzelnen Schritte ist nachfolgend aufgeführt:

  1. Datenerfassung: Format der 5-Minuten-Niederschlagszeitreihe

  2. Datenaufbereitung: Bildung von jährlichen Serien für definierte Dauerstufen

  3. Extremwertstatistiche Auswertung: Schätzung von Parametern und Wiederkehrzeiten

  4. Vergleiche zwischen lokaler Extremwertstatistik und KOSTRA-DWD-2020

Benötigte Software

Zunächst ist es erforderlich, R zu installieren. Es wird zudem dringend empfohlen, auch R Studio zu installieren. Hierbei handelt es sich um eine Entwicklungsumgebung (IDE), die das Arbeiten mit R wesentlich erleichtert. Eine Anleitung zur Installation beider Programme steht hier (für alle gängigen Betriebssysteme) zur Verfügung.

Nach der Installation der beiden Programme ist ein neues R-Skript zu erstellen (File > New File > R Script). In diesem Dokument kann nun Zeile für Zeile der hier vorgestellte Code hinzugefügt und ausgeführt werden, um die Ergebnisse der lokalen Extremwertanalyse, die für die Station Görlitz durchgeführt wurde, zu reproduzieren.

Zunächst ist es erforderlich, das für das Arbeitsblatt DWA-A 531 entwickelte R-Package “Nextreme” zu installieren und einzubinden.

  1. Das Paket kann aus der bereitgestellten Archiv-Datei (Nextreme.zip) mit folgenden Schritten installiert werden: Tools > Install Packages > Install from: Package Archive File (.zip; .tar.gz) > Browse to the package location > Install.

  2. Das Package kann aber auch in seiner aktuellsten (Entwicklungs-)Version direkt von GitHub installiert werden:

# install.packages("pak")
pak::pak("dimfalk/Nextreme")

Die von “Nextreme” verwendeten Dritt-Packages sollten aufgrund von definierten Abhängigkeiten mit der Installation des Packages automatisch verfügbar sein. Sollte dem nicht so sein, können diese wie folgt manuell nachinstalliert werden:

install.packages("evd")
install.packages("lmomco")
install.packages("lubridate")
install.packages("terra")

Um “Nextreme” zu laden, verwenden Sie den folgenden Befehl:

library("Nextreme")

2. Datenaufbereitung: Bildung von jährlichen Serien für definierte Dauerstufen

Für die 5-Minuten-Niederschlagsreihen der Station Görlitz werden für jede Dauerstufe jährliche Maxima bestimmt und somit eine jährliche Serie gebildet. Dies erfolgt hier nach den im Arbeitsblatt DWA-A 531 beschriebenen Schritten, die sich nachfolgend beschrieben finden:

2.1 Ermittlung von Regenhöhen bestimmter Dauerstufen aus den Grunddaten

Ziel ist die Berechnung der jährlichen Maxima für jede der betrachteten Dauerstufen. Zu diesem Zweck kann die Funktion jaehrliche_maxSerie() verwendet werden. Hier wird ein Zeitraum von 4 Stunden (DSDmin) verwendet, um unabhängige Niederschlagsereignisse voneinander zu trennen. Da die Niederschlagsdaten in Form von 5-Minuten-Summen vorliegen, wird das Intervallargument (Intervall) auf 5 gesetzt. Um die Parameter der Extremwertverteilung zu ermitteln, sind die maximalen jährlichen Niederschlagsintensitäten pro Dauerstufe erforderlich. Aus diesem Grund geben wir SerieTyp = “INT” an, um die maximalen Intensitäten als Ausgabe zu erhalten.

Goerlitz_maxIntSerie <- jaehrliche_maxSerie(Regendaten_01684, 
                                            Dauern = c(5, 10, 15, 30, 60, 120, 360, 720, 1440, 2880, 4320, 10080), 
                                            DSDmin = 240, 
                                            Intervall = 5,
                                            SerieTyp = "INT")

2.2 Berücksichtigung der Intervalllänge

Da die Niederschlagsreihe in 5-Minuten-Intervallen verfügbar ist, wird die jährliche Serie der Dauerstufen von 5, 10, und 15 Minuten korrigiert (vgl. Tab. 1 in DWA-A 531). Zu diesem Zweck kann die Funktion Intervall_Korrektur() verwendet werden. Entsprechend der zeitlichen Auflösung der Zeitreihe wird das Intervallargument (Intervall) auf 5 gesetzt, sodass Dauerstufen bis 20 Minuten bei der Korrektur berücksichtigt werden.

Goerlitz_maxIntSerie_korr1 <- Intervall_Korrektur(Goerlitz_maxIntSerie, Intervall = 5)

2.3 Stationarität und Sprungkorrektur bei kurzen Dauerstufen

Da sich der Sensortyp an der Station Görlitz über die Zeit ändert, wird überprueft, ob die jährliche Serie der kurzen Dauerstufen (5, 10, 15 und 30 Minuten) eine sprunghafte Instationarität aufweisen, die dem Datum des Sensorwechsels entspricht. Wenn es eine solche sprunghafte Instationarität gibt, wird der Sprung eliminiert.

HINWEIS: Dieser Schritt wird an der Stelle lediglich durchgeführt, um ein Anwendungsbeispiel zu zeigen. Laut Arbeitsblatt DWA-A 531 sollte eine Sprungkorrektur getestet werden, wenn es einen Sensorwechsel von analog zu digital gab. An der Station Görlitz sind in diesem Beispiel alle Sensoren digital, sodass eine Sprungprüfung und -korrektur eigentlich nicht erforderlich wäre. Hier wird dieser Schritt bloß gezeigt, um einen vollständigen Arbeitsablauf darzulegen.

Zu diesem Zweck kann die Funktion Sprung_Korrektur() verwendet werden. Zusätzlich zur Eingabe der jährlichen Serie (Goerlitz_maxIntSerie) benötigt die Funktion das Datum des Sensorwechsels in Form eines Date()-Objektes als weiteres Argument.

Goerlitz_maxIntSerie_korr2 <- Sprung_Korrektur(Goerlitz_maxIntSerie_korr1, wechselDatum = as.Date("1991-01-01"))

# Differenz vor und nach Anwendung der Funktion `Sprung_Korrektur()` überprüfen.
all.equal(Goerlitz_maxIntSerie_korr1, Goerlitz_maxIntSerie_korr2)
#> [1] TRUE

Da in dem gewählten Beispiel kein Sprung in der Zeitreihe vorliegt, entspricht die Eingabe auch dem von der Funktion Sprung_Korrektur() zurückgegebenem Ergebnis.

3. Extremwertstatistische Auswertung

Nachfolgend werden Beispiele für die Extremwertanalyse an der Station Görlitz gezeigt.

3.1 Schätzung der Parameter zur Beschreibung der Extremwertverteilung über alle Dauerstufen

Ziel ist die Anpassung der generalisierten Extremwertverteilung (GEV) an die jährlichen Serien der Niederschlagsintensität. Die Koutsoyiannis-Methode, wie im Arbeitsblatt DWA-A 531 beschrieben, wird zur Normalisierung der Intensitäten über alle Dauerstufen verwendet.

Zu diesem Zweck kann die Funktion Parameter_Schaetzung() verwendet werden, um die Parameter der Extremwertverteilung auf Basis der jährlichen Serien zu schätzen. Als Funktionsargumente sind die Dauerstufen und die Art der Verteilung, die angepasst werden soll, anzugeben. Wie im Arbeitsblatt DWA-A 531 wird hier die GEV-Verteilung mit einem festen Formparameter von -0.1 (Fréchet-Typ) verwendet. Deshalb lauten die Argumente methGEV =“GEV” , formTyp = “FIX” und Gamma = -0.1. Da die jährliche Serie der Intensitäten (mm/h) als Eingabe verwendet wird, ist SerieTyp = “INT” zu definieren. Im Falle von jährlichen Serien der Niederschlagshöhe (mm) als Eingabe, ist SerieTyp = “VOL” zu verwenden.

HINWEIS: Die Funktion Parameter_Schaetzung() kann entweder eine GEV oder eine Gumbel-Verteilung (Formparameter von 0.0) anpassen. Für die Gumbel-Verteilung (methGEV = “GUM”) bleiben die Argumente formTyp und Gamma unberücksichtigt. Für die GEV kann der Formparameter hingegen auch frei aus L-Momenten geschätzt werden (mit formTyp = “CON”). In diesem Fall wird Gamma nicht beruecksichtigt. In allen Fällen werden die maximalen Intensitäten über die angegebene Dauerstufen normalisiert.

N_pars <- Parameter_Schaetzung(Goerlitz_maxIntSerie_korr2, 
                               Dauern = c(5, 10, 15, 30, 60, 120, 360, 720, 1440, 2880, 4320, 10080), 
                               methGEV = "GEV", 
                               formTyp = "FIX", 
                               Gamma = -0.1,
                               SerieTyp = "INT")
N_pars
#>         Mu    Sigma Gamma      Theta       Eta       KW
#> 1 16.88105 5.610762  -0.1 0.06259154 0.7499916 2.412742

Beim Ergebnis der Funktion Parameter_Schaetzung() handelt es sich um einen einzeiligen Dataframe, der die berechneten Parameter der Extremwertverteilung des Niederschlags enthält:

Mu - der GEV-Lokationsparameter, Sigma - der GEV-Skalenparameter, Gamma - der GEV-Formparameter, Theta - 1. Koutsoyiannis-Parameter, Eta - 2. Koutsoyiannis-Parameter,

während KW die Kruskal-Wallis-Teststatistik ist, die bei der Optimierung der Parameter erreicht wurde.

3.2 Schätzung der Niederschlagshöhe für angegebene Dauerstufen und Wiederkehrzeiten

Ziel ist die Berechnung der Wiederkehrzeiten von beobachteten Niederschlagshöhen in bestimmten Dauerstufen auf der Grundlage der zuvor berechneten Parameter der Extremwertverteilung.

Zu diesem Zweck kann die Funktion Quantil_Schaetzung() verwendet werden. Neben den Parametern (N_pars), den Dauerstufen (Dauern) und den Wiederkehrintervallen (Tn), sollte auch die GEV-Methode (methGEV) angegeben werden. In diesem Fall wird SerieTyp = “VOL” definiert, um Niederschlagshöhen (mm) als Output zu erhalten. Ist man an Niederschlagsintensitäten (mm/h) interessiert, lautet SerieTyp = “INT”.

H_quas <- Quantil_Schaetzung(N_pars, 
                             Dauern = c(5, 10, 15, 30, 60, 120, 360, 720, 1440, 2880, 4320, 10080),
                             Tn = c(1, 2, 3, 5, 10, 20, 30, 50, 100), 
                             methGEV = "GEV",
                             SerieTyp = "VOL")

3.3 Schätzung der Unsicherheitsbereiche

Ziel ist die Durchführung eines Bootstraps, um die Unsicherheit der Stichprobe bei der Anpassung der Parameter zu berücksichtigen.

Zu diesem Zweck kann die Funktion Unsicherheit_Schaetzung() verwendet werden. Neben den bereits im Rahmen von Parameter_Schaetzung() und Quantil_Schaetzung() bekannten Argumenten zur Bestimmung von Parametern und Extremwerten sind drei weitere notwendig:

nBoots - zur Angabe der gewünschten Anzahl von Realisierungen, rSeed - eine beliebige Zufallszahl, um sicherzustellen, dass das Ergebnis reproduzierbar bleibt, Konfidenzgrenzen - zur Angabe der Quantils der oberen (Ko) und unteren Konfidenzintervallgrenzen (Ku).

Die geschätzten jährlichen Serien der maximalen Intensitäten werden nBoots-mal mit Zurücklegen neu gesampelt, um die Stichprobenunsicherheit zu berücksichtigen. Anschließend werden für jede Iteration die Parameter neu geschätzt. Auf diese Weise erhält man nBoots Realisierungen der Parameter, die als Grundlage für die Berechnung von Konfidenzintervallen der Parameter und Quantile verwendet werden.

KI <- Unsicherheit_Schaetzung(Goerlitz_maxIntSerie_korr2,
                              Dauern = c(5, 10, 15, 30, 60, 120, 360, 720, 1440, 2880, 4320, 10080),
                              methGEV = "GEV",
                              formTyp = "FIX",
                              Gamma = -0.1,
                              SerieTyp = "VOL",
                              Tn = c(1, 2, 3, 5, 10, 20, 30, 50, 100),
                              nBoots = 100,
                              rSeed = 42,
                              Konfidenzgrenzen = c(0.025, 0.975))

3.5 Schätzung der Wiederkehrzeiten nach Dauerstufe und Niederschlagshöhe

Mit der geschaffenen Grundlage ist es nun möglich, die Jährlichkeit eines beobachteten Niederschlagsereignisses pro gewählter Dauerstufe zu bestimmen.

Zu diesem Zweck kann die Funktion Tn_Schaetzung() verwendet werden. Als Argumente gehen die geschätzten Parameter der Extremwertverteilung N_pars, die beobachtete Niederschlagsmenge hN in mm sowie die betrachtete Dauerstufe Dauern ein. Zudem ist anzugeben, ob Parameter für die Gumbel- oder GEV-Verteilung verwendet wurden.

Während eines Starkregenereignisses am 18.07.2010 wurden an der Station Görlitz eine Niederschlagshöhe von 58.6 mm innerhalb von 6 Stunden gemessen. Basierend auf den geschätzten Parametern beträgt die bestimmte Wiederkehrzeit somit:

Tn_Ereignis <- Tn_Schaetzung(N_pars, hN = 58.6, Dauern = 360, methGEV = "GEV")
Tn_Ereignis
#>     hN   D Tn
#> 1 58.6 360 23

Die Funktion Tn_Schaetzung() gibt einen Dataframe mit der beobachteten Regenhöhe hN (mm), der Dauerstufe D (min) und der geschätzten Wiederkehrzeit Tn (a) zurück.

Diese Vignette zeigt, wie mit dem Paket Nextreme eine lokale Extremwertanalyse gemäß Arbeitsblatt DWA-A 531 durchgeführt werden kann.
